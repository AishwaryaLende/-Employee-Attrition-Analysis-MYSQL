# Employee Attrition Analysis Using MySQL

This project showcases SQL-based data analysis on an Employee Attrition dataset to extract meaningful business insights from employee records. It covers basic to advanced SQL queries including filtering, aggregation, sorting, subqueries, and conditional logic. The main objective of this project is to demonstrate SQL proficiency through real-world employee data exploration and analysis.

# Key Insights

1) Most employees belong to Bangalore city.

2) PaymentTier 3 employees are higher in number.

3) Employees with lower experience are more likely to leave the company.

4) Benched employees show a higher attrition rate.

5) Majority of employees joined after 2015.

6) Employees with higher PaymentTier are less likely to leave.

7) Average employee age is around the mid-20s.

# SQL Highlights

1. Basic retrieval queries (e.g., displaying all employee records)

2. Employee filtering based on age, gender, city, and payment tier

3. Aggregation queries using GROUP BY and COUNT

4. CASE statements for employee classification

5. Subqueries for average-based comparisons

6. Sorting and ordering employee data using ORDER BY

7. Advanced filtering and duplicate record analysis
