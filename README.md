# Employee Attrition Analysis using MySQL

## Project Overview
This project analyzes employee attrition data using MySQL queries.  
The project focuses on employee insights, salary tier analysis, city-wise employee count, employee experience, and attrition trends.

## Tools Used
- MySQL
- Employee Dataset
- SQL Queries

## SQL Concepts Used
- SELECT Statements
- WHERE Clause
- GROUP BY
- ORDER BY
- Aggregate Functions
- Subqueries
- CASE Statements

## Key Insights
- Most employees belong to Bangalore city
- PaymentTier 3 employees are higher in number
- Benched employees show higher attrition
- Employees with higher PaymentTier are less likely to leave
